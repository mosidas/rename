# Finder で選んだファイルを rename で開く

Automator のクイックアクションを作り、Finder で選んだファイルを右クリックのメニューから rename に渡す手順である。対象は rename を `/Applications` に入れた利用者で、初回に 1 度だけ行う。rename 本体の使い方は README にある。

## 前提

- `rename.app` が `/Applications` にある。ほかの場所に入れたときは、8. のスクリプトのパスをその場所に合わせる。
- Automator(macOS に同梱)を使う。

## クイックアクションを作る

1. Automator を開く。書類の種類を選択する画面が出る。
2. 「クイックアクション」を選択し、「選択」を押す。空のワークフローが開く。
3. 上部の「ワークフローが受け取る現在の項目」を「ファイルまたはフォルダ」にする。
4. その右の「検索対象」を「Finder.app」にする。
5. 左のアクションの一覧で「シェルスクリプトを実行」を検索する。一覧にその 1 件が出る。
6. 「シェルスクリプトを実行」をダブルクリックする。右のワークフローにアクションが加わる。
7. 加わったアクションの「入力の引き渡し方法」を「引数として」にする。
8. スクリプトの欄を次の 1 行に置き換える。

   ```sh
   /Applications/rename.app/Contents/MacOS/rename "$@"
   ```

9. `⌘S` を押し、名前を「rename で開く」にして保存する。保存先は `~/Library/Services/` になる。
10. Finder でファイルを右クリックし、「クイックアクション」の中に「rename で開く」が出ることを確かめる。

## 使う

Finder でファイルを選択し(複数でもよい)、右クリックして「クイックアクション」から「rename で開く」を選択する。rename が起動する。選んだファイルは読み込まれた状態で表示される。rename がすでに起動しているときは、既存のウィンドウに読み込まれ、そのウィンドウが前面に出る。

## うまくいかないとき

- 「クイックアクション」に「rename で開く」が出ないときは、システム設定 > プライバシーとセキュリティ > 機能拡張 > Finder 拡張機能 で Automator を有効にする。
- rename が起動しないときは、8. のスクリプトのパスが `rename.app` の実際の場所と一致しているかを確かめる。
